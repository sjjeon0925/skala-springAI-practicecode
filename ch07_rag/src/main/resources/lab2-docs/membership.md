# SKALA 스토어 멤버십 등급·포인트 규정 (2026-07 개정)

## 1. 등급 구성

| 등급 | 산정 기준 (직전 12개월 누적 구매액) | 적립률 |
| --- | --- | --- |
| 실버 | 가입 시 기본 등급 | 1% |
| 골드 | 100만 원 이상 | 3% |
| 플래티넘 | 500만 원 이상 | 5% |

## 2. 등급 산정 주기

- 매월 1일, 직전 12개월 누적 구매액을 기준으로 재산정한다.
- 등급이 오르면 즉시 적용되고, 내려가면 다음 달 1일부터 적용된다.
- 신규 가입 회원은 실버 등급으로 시작한다.

## 3. 포인트 적립

- 적립률은 등급별로 다르며, 결제 금액(배송비 제외)의 일정 비율을 적립한다.
- 쿠폰·포인트 사용분에는 적립되지 않는다.
- 적립 포인트는 구매 확정일로부터 3영업일 이내 지급된다.

## 4. 포인트 사용

- 1점 = 1원으로 사용할 수 있다.
- 최소 사용 단위는 1,000점이다.
- 주문 금액의 최대 50%까지 포인트로 결제할 수 있다.

## 5. 포인트 유효기간

- 적립일로부터 **1년**이며, 만료 30일 전 알림을 발송한다.
- 유효기간이 지난 포인트는 자동 소멸되며 복원되지 않는다.
